# Balochistan Winter Programme: Urdu lesson plans

One day, one level = one `common_*.py` data file (single source of truth) + one `doc_*.py` per document (Lesson Plan, Prep Pack, Worksheet). Change the data, rebuild, look at the PNGs. Nothing is drawn by hand.

60-minute lessons, last 10 = exit check. Urdu for Urdu: no English glosses in children's text (small Poppins English tags on teacher-facing section headings only). No Rumi logo.

## Inputs (ask, never assume)

1. The **current Urdu planner PDF** (latest seen: `TaRL_Urdu_SLOs_and_33Day_Planner_28Oct.pdf`). A newer planner replaces it: diff the day's SLOs first and tell the user what moved.
2. The user's lesson-plan rules (approved words only, hear 4 to 5 children, tracker, no pass-mark line: write `[PENDING: ...]`, never guess).
3. Books if the day cites them (Balochistan Grade 1 Urdu book, Lesson 1 printed p.1 gave the Day 1 Beginner picture words).

## What is built (Day 1 of each level)

| Level | Planner day | SLO | Data | Docs | Build keys |
|---|---|---|---|---|---|
| 1 Beginner | Teach new letters ا ب پ ت ٹ ث, taught by SOUND not letter name | U-B-01/02/03, support U-B-04 | `common_n*.py` (28 Oct, six letters); `common_u*.py` (27 Oct, five letters) | `doc_*_n.py`, `doc_*_u*.py` | `lpn prepn wsn` (28 Oct); `lpu3 prepu3 wsu2` (27 Oct) |
| 2 Intermediate | Teach and model, reading words | U-I-01 (+ U-I-11 forms) | `common_i.py` | `doc_lp_i.py`, `doc_prep_i.py`, `doc_ws_i2.py` (interactive) | `lpi prepi wsi2` |
| 3 Advanced | Teach and model, agreement in sentences | U-A-08, support U-A-10 | `common_a.py` | `doc_lp_a.py` (5 pp), `doc_prep_a.py` (7 pp), `doc_ws_a.py` (3 pp, interactive) | `lpa prepa wsa` |

Advanced design: one frame, ADJECTIVE + NOUN + VERB + ہے/ہیں, four forms (ایک لڑکا / کئی لڑکے / ایک لڑکی / کئی لڑکیاں). Every sentence is generated by `words()` / `sent()` from the word tables, so the three documents cannot disagree. Feminine plural keeps the feminine-singular adjective and verb; only noun and helper change. Kinds are shown as نام / کیسا / کام (formal اسم / صفت / فعل in brackets) with black-and-white print cues: noun solid border, adjective dashed, verb dotted, helper grey. Only two regular plural patterns (ا to ے, ی to یاں); irregular plurals such as کتاب to کتابیں are left for Days 2 and 3.

## Build

Needs Python 3.8+, `pillow`, `pymupdf`, Microsoft Edge (or set `EDGE_PATH`).

```powershell
cd balochistan-urdu-lp\engine
$env:PYTHONIOENCODING='utf-8'
python -W ignore build.py lpa prepa wsa     # keys in the table above
```

- **Run from PowerShell**, not bash (a bash-launched build can silently skip the PDF).
- Output (`<key>.pdf`, `png/<key>_pN.png`, `<key>.html`) is gitignored.
- Overflow is reported through the PDF title (`OVF:`). It only checks `.content`, not collisions with the absolutely pinned footers, so **always look at every PNG**.

## Workflow (the user's standing rules)

1. Build, then show **PNG previews first** (copy them to a Desktop `preview_vN` folder; the user cannot see the scratchpad). Save PDFs only after the user says "approve" (or asks for them outright).
2. Save as a new `_vN`; **never overwrite** an earlier version. One version per document at the original text size: do not make "larger text" variants unless asked again.
3. Prep Pack is its own document, never merged into the Lesson Plan.
4. Name PDFs `L<level> Urdu Day <n> - 1 Lesson Plan_v1.pdf`, `- 2 Prep Pack_v1.pdf`, `- 3 Student Worksheet_v1.pdf`.

## Standing layout edits (apply to every new day and level)

Full list in [reference/layout-rules.md](reference/layout-rules.md). Headlines:
- Pale print-safe tiles (dark text on tint, coloured border), never white-on-colour; the workbook is printed black and white.
- Page 1 order: learning outcomes, then Today's goal. No pass-mark line.
- Teacher spoken lines in speech boxes starting «کہیں:».
- We-do headings in English only, with a minutes pill; "Check before moving on" and "While you walk around" are a pale footer pinned to the page bottom; "Score and decide" pinned to the bottom of page 5.
- Exit check: refers to Worksheet page 2 (children's task) and the teacher's task, plus a small answer table. Wording: **دائرہ لگائیں**, never گھیریں.
- Worksheets are interactive (star row, spinner, cut-out cards, home task), not just print-and-fill.
- Keep ٹریکر as is; no word تختی (say کاپی); avoid ٹیلی, چیلنج, گھماؤ (use گنتی, گھر کا کام).

## Make a new day or level

1. Copy the closest `common_*.py` and replace the data. Keep the `assert` block: it enforces approved words, no straight-across answers, one error per wrong sentence, and cross-document consistency (including the minutes: warm-up 1+4, hook 1+2+2, I do 4x5, We do 3x4, You do 3+3+2, exit 6+4).
2. Copy the matching three `doc_*.py`, point them at the new data, add keys to the `mods` map in `build.py`.
3. Pictures: text-free object pictures only, via `kie-ai-imagegen` (`nano-banana-pro`) through `kie_gen*.py`. Urdu is **always live Noto Nastaliq text, never drawn by the image model**. Raw PNGs go to `img/raw`, `build.py` converts them to `img/*.jpg`. Set `AGENT_SKILLS_REPO` to the folder holding `.env` (`KIE_API_KEY`) and `skills/kie-ai-imagegen`; never print the key. Kie error 433 = daily cap: stop, do not retry in a loop. For counted pictures, say "exactly three" in the prompt and check the contact sheet.
4. Build, view every PNG, then ask for approval.

## Gotchas

- f-strings in `doc_*.py`: inline `<style>` needs doubled braces `{{ }}`.
- Class names `.n/.a/.v/.h` clash with the worksheet `.task .n` badge; word-role chips use `.rn/.ra/.rv/.rh`.
- A scale wrapper multiplies pt sizes per page, including `.pin` CSS: append pinned-footer CSS after scaling.
- Nastaliq is thin and tall: give line-height room, and check faint lines in the PNG before printing.
- Ordering rules in word lists: no two same-kind words adjacent; b/p and t/ṭ style look-alikes kept apart in call lists.
