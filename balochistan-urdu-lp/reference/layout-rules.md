# Urdu LP layout rules (standing edits)

Edits the user made while reviewing Beginner Day 1 (v1 to v4), applied by default to every new Urdu day and level.

**Workflow:** PNG previews first; PDFs only after "approve"; new `_vN` each time, never overwrite. Prep pack stays separate. One version per document at original text size.

**Lesson plan**
- Pale print-safe tiles, never white-on-colour. Goal box and "Check before moving on" pale too.
- Page 1: learning outcomes, then Today's goal. No "By the end of today", "Five letters only", "Book and documents" or Key facts boxes, no pass-mark line.
- Never show the same letters or words twice in one place.
- Teacher lines in speech boxes starting «کہیں:».
- We-do step headings in English only (1 · Say the sounds) with a minutes pill.
- "Check before moving on" + "While you walk around": pale footer pinned to the We-do page, space left above.
- Exit check refers to worksheet page 2 and the teacher task, plus a small answer table. "Score and decide" is a pale footer pinned at the bottom of page 5.
- Pages 1 and 2 fill the page with bigger text and spacing, not gaps.
- Small text near-black, not grey, so it prints.
- No تختی; say کاپی. Poppins English tags on section headings. No Rumi logo.

**Exit-ticket wording:** «دائرہ لگائیں» (circle), not «گھیریں».

**Worksheet:** interactive (star row to colour, spinner, cut-out cards, home task «گھر کا کام»). Print the cut-out page single-sided. Avoid ٹیلی, چیلنج, گھماؤ.

**Why:** the user prints these for teachers in Balochistan, often in black and white, and reviews page by page.
